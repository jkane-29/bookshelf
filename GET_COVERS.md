# How to Get Book Covers

The easiest way to get accurate book covers is to download them manually. Here's how:

## Quick Method (Recommended)

For each book, follow these steps:

1. **Google Image Search**: Search for `"[book title] [author] book cover"`
2. **Right-click** on a high-quality cover image
3. **Save Image As...** to the `covers/` folder
4. Name it exactly as shown in the list below

## Best Sources for Covers

1. **Google Images** - Search `"book title author book cover"`
   - Look for high-quality, clear covers
   - Aim for images at least 300-400px tall

2. **Goodreads** - https://www.goodreads.com
   - Search for the book
   - Right-click the cover → Save image

3. **Amazon** - https://www.amazon.com
   - Search for the book
   - Right-click the cover → Save image
   - Often has high-res covers

4. **Open Library** - https://openlibrary.org
   - Search for the book
   - Click on it, then save the cover

## Tips

- **JPG or PNG** both work fine
- **Size**: Aim for covers that are 400-600px tall minimum
- **Aspect ratio**: Standard book covers (taller than wide) work best
- **Quality**: Higher resolution = better looking shelf
